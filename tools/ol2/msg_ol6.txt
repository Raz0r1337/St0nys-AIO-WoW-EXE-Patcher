No. 68 outline: fix "own character only where hidden", Y by default [BETA]

With "only where hidden" the own character was outlined everywhere: the
invisible copies that mark the outline still had STENCILZFAIL REPLACE
from the figure pass, so they also marked the outline where they failed
the depth test - in front of walls just like behind them. Things drawn
later (e.g. a plate in front of the character) cleared it again.

- The copies now keep the stencil where the depth test fails, so only
  the hidden parts get an outline.
- Their depth is pulled forward a bit (VS c4 + KZ * c5, KZ computed from
  the projection, about 0.001 * distance^2 yards); otherwise there would
  be a line on the ground right under the feet.
- "Own character outlined only where it is hidden?" is now Y by default
  (value.outline=hidden); "none" is shown as "all N".
- Emulation test extended (ZFAIL of the copies, depth offset); PATCHES
  and README updated; byte table rebuilt (unchanged).
