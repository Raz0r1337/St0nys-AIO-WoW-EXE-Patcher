Add patcher.sh: start file for Linux

The patcher is written for Windows, but it also runs natively on Linux
with PowerShell 7 (pwsh), no Wine needed. patcher.sh is the counterpart
to patcher.bat: it changes to its own folder, checks that pwsh is
installed (otherwise a short hint pointing to the docs) and starts
apply_patches.ps1 with all parameters passed through. It is stored as
executable with LF line endings (.gitattributes); the Windows files stay
unchanged.

The READMEs get an "On Linux" section (install PowerShell 7, start
./patcher.sh; may also work on a Mac, untested), a pointer under
Requirements and patcher.sh in the file list.
