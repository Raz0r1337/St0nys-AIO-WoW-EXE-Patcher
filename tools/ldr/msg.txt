Same naming for all DLL loaders; voice.dll entry aligned, BETA

All five DLL loaders load their DLL with LoadLibraryA when WoW starts;
they only differ in where they hook in. The AwesomeWotlkLib and
WotLKExtensions loaders were still called "Enable ... support", now
they read "Load ... at startup" like the others.

The voice.dll loader follows the same pattern: "Load voice.dll at
startup (voice chat by St0ny) [BETA]" with the note "requires
mod-voicechat". Its ALPHA mark is now BETA, the box in PATCHES says
the module is not finished yet and the patch is dev-only for now.

Names and docs only, no patch bytes change (byte table unchanged).
